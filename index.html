🛡️ Panel admin

Konfigurasi notifikasi HP

Buat kunci VAPID satu kali. Salin kunci privat ke Supabase Edge Function Secrets dengan nama VAPID_PRIVATE_KEY. Jangan bagikan kunci privat kepada siapa pun.

Setelah disimpan di Secrets, buat Database Webhook untuk tabel notifications pada event INSERT, arahkan ke Edge Function push-notifications, metode POST, dan pilih header otorisasi service key. Panduan akan saya berikan saat bagian ini siap.
