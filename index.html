🛡️ Panel admin

Konfigurasi notifikasi HP

Buat kunci VAPID satu kali. Salin kunci privat ke Supabase Edge Function Secrets dengan nama VAPID_PRIVATE_KEY. Jangan bagikan kunci privat kepada siapa pun.

Trigger database untuk tabel notifications sudah aktif dan meneruskan event ke Edge Function push-notifications; jangan membuat webhook duplikat. Jika mengganti pasangan kunci, perbarui secret VAPID_PRIVATE_KEY sebelum perangkat mengaktifkan notifikasi kembali.
